# Seasonal Low-Cloud Feedback Project

**Scope:**  
This project investigates the seasonal variability of low-cloud feedbacks (LCF–EIS–SWCRE relationships) using MODIS, CERES, and ERA5 datasets, in order to constrain climate sensitivity and reduce model uncertainty.

**Data sources:**  
- MODIS MCD06COSP (Low Cloud Fraction)  
- CERES EBAF (Shortwave Cloud Radiative Effect)  
- ERA5 (Estimated Inversion Strength and Meteorological Fields)

**Time span:** 2003–2022  
**Regions:** Subtropical stratocumulus decks (SEP, SEA, NEP, NEA, SEI)  
**Outputs:** Processed datasets, diagnostics, harmonic fits, and seasonal phase-locking metrics.  

**Structure:**  
-    Raw and processed datasets  
-   Analysis results and derived metrics  
-   Generated plots and visualisations
-    Execution logs
-   Configuration files for reproducible workflows
